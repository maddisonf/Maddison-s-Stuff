# maddison's stuff ♡

A customizable personal dashboard based on the original Maddison's Stuff website.

## What's new

This version adds:

- Custom website title
- Custom subtitle
- Custom home quote
- Custom birthday date
- Accent color customization
- Create, edit, and delete classes
- Custom class emoji/icon
- Custom class card colors
- Custom class descriptions
- Create, edit, complete, filter, and delete assignments
- Quick links can be added and deleted
- Goals can be added, checked off, and deleted
- Editable volleyball notes
- Editable creative-project notes
- Editable memory/journal section
- Events and reminders
- Calendar event indicators
- Planner page
- Quick notes
- Planner checklist
- Upcoming assignment view
- Export a complete JSON backup
- Import a previous JSON backup
- Browser persistence using localStorage
- Responsive mobile layout

## GitHub Pages

Upload all files to a GitHub repository:

- `index.html`
- `style.css`
- `script.js`

Then:

1. Open **Settings**
2. Open **Pages**
3. Select **Deploy from a branch**
4. Select `main`
5. Select `/ (root)`
6. Save

## Data

The site stores information in the browser's localStorage.

Use **Export backup** regularly if you want a portable copy of your dashboard.

Importing a backup replaces the current dashboard data.
